# 錄製與後製合成

網頁做完 + 音檔合成完之後，**Auto 模式 + 螢幕錄影可以一鏡到底**——
不需要手動點擊推進 step、也不需要後製對音檔。

如果你不做音檔，仍可走「手動點擊 + 後製配音」的傳統路徑（在文件末尾）。

---

## 建議流程：Auto 模式一鏡到底

### 前置

- 章節程式碼做完，每章都有 `narrations.ts`
- 已經跑過 `pnpm run extract-narrations` + `pnpm run synthesize-audio`，
  `public/audio/<id>/<step>.mp3` 全部就位
- `pnpm run dev` 跑著，瀏覽器能開啟頁面（`npm run dev` 亦可 —— 看 `.pm`）

### 錄製步驟

1. **瀏覽器全螢幕**（F11 / Ctrl+Cmd+F），URL 改成
   `http://localhost:5173/?auto=1`
2. 看到 "Press SPACE to start" 遮罩 = Auto 模式就緒
3. **打開螢幕錄影**（QuickTime / OBS / Cmd+Shift+5），開始錄
4. **按一次 Space** → 遮罩消失 → step 0 出現，1.mp3 自動播 →
   播完自動推進到 step 1 → 2.mp3 → … → 最後一個 step 播完 → 停在終態
5. **停止錄影** → 後製裁掉頭尾（按 Space 那一下、最後停在終態的尾巴）就是
   成品

整個過程**完全不用點滑鼠**。影音天然同步，不需要後製對軌。

> **Auto 模式嚴格依音檔結束推進**（+ 200ms 緩衝），沒有「等動畫跑完」
> 的保底。如果你看到某步動畫被切了一半 → 說明該 step 動畫長於旁白，
> 回章節程式碼改：寫更長旁白 / 拆 step / 調動畫速度。

### 螢幕錄影工具

| 平台 | 工具 | 設定 |
|---|---|---|
| macOS | Cmd+Shift+5 → 錄製選定視窗 | 選瀏覽器視窗；瀏覽器全螢幕後輸出就是 1920×1080 |
| macOS | QuickTime → 檔案 → 新增螢幕錄製 | 同上 |
| 跨平台 | OBS Studio | 視窗擷取，Canvas 1920×1080，60fps |

### 模式速查

| URL / 快捷鍵 | 行為 |
|---|---|
| 直接開啟（預設） | Manual：點擊 / ←→ 推進，不播音檔 |
| `?audio=1` 或按 `M` | Audio：進入 step 自動播音檔，但**手動點滑鼠推進** |
| `?audio=1` + 再按 `M` | Auto：進入 step 自動播 + 自動推進（錄製用） |
| Auto 模式下首次按 `Space` | 啟動 Auto 播放（繞過瀏覽器自動播放限制） |

也可以把滑鼠移到右上角，會出現一個隱藏的模式切換按鈕。

## 備用流程：沒合成音檔時手動錄影

如果你跳過了音檔合成（`Checkpoint Audio` 選了「不合成」），照舊方法：

1. 瀏覽器全螢幕 → 開啟 `localhost:5173`（預設 Manual 模式）
2. **重新整理一次**清空歷史 step
3. 開始錄影 → 依旁白節奏點擊空白推進 step
4. 後製用任何剪輯軟體配音 + 調時間軸

### 後製工具

| 工具 | 適合 |
|---|---|
| **DaVinci Resolve** | 跨平台免費、能處理多段音檔拼接 |
| **iMovie** | macOS 簡單情境 |
| **CapCut / 威力導演 PowerDirector** | 短影音風格快速加字幕 |
