# Anchor: list-reveal（列舉型逐個揭示）

> ⚠️ **這是結構示意，不是抄襲樣板**。先走 [`../../CHAPTER-CRAFT.md`](../../CHAPTER-CRAFT.md)
> Part 0 五問。本 anchor 給的是「列舉型章節的結構骨架」（單一格線 N 個插槽 +
> 每 step 只填一個插槽 + 位置不重排）——保留這個**結構**，**依本專案的
> 主題 + 內容換動作選型**。反過來照抄 = [`../../CHAPTER-CRAFT.md`](../../CHAPTER-CRAFT.md)
> Part 5 第 8 條「整章只用一種進場動畫」同質化反模式。

## 定位

旁白說「三件事 / 四個原因 / N 個特性」時，**每項 1 step 逐個揭示**。
影片中段最常用的章節類型，**最容易做成簡報** —— 這是為什麼需要 anchor。

## 適用情境

- 「<主體> 強在哪 → 三件事」
- 「選購 <X> → 四個角度」
- 「為什麼我喜歡 <X> → 五個理由」
- 任何「主題 + N 個並列子項」的結構

## 假設的 outline.md 章節段（抽象）

```markdown
## 4. <chapter-id> — <主題 N 件事>（N+1 steps）

- **step 1** (~3s) — masthead 引子「<N 件事>」
- **step 2** (~6s) — 第 1 件：<標題> + <article 抽來的細節>
- **step 3** (~6s) — 第 2 件：<標題>
- ...
- **step N+1** (~6s) — 第 N 件：<標題>
```

## 關鍵節奏決策

| step | 視覺版面 |
|---|---|
| 1 | 中心引子大字 + 序號 01/02/.../N 佔位（**不顯示內容**，純佔位） |
| 2 | 「01」插槽填充：標題 + 簡短說明 + accent 編號；其餘仍是 ghost |
| 3 | 「02」填充；01 已啟用變次級；其餘仍 ghost |
| ... | 當前插槽填充；之前的啟用降級；之後的 ghost |

## CHAPTER-CRAFT.md Part 0 原則 8 的核心實作

> 「版面不重排，只是儲存格內容變化」

整個章節只有**一個格線版面**，N 個插槽的 React 節點位置完全不變。
變的只是每個插槽的內容狀態（ghost / active / past）。這樣：
- 儲存格不會重排 → 視覺穩
- 每點一次只有「一個插槽變化」→ 觀眾視線明確鎖定新揭示的項目

**反模式**：每點一次重新渲染整個版面 → 已揭示的項目也跟著抖動 / 重新
進場 → 觀眾不知道該看哪。

## 關鍵手段（地板線）

| 面向 | 這個 anchor 怎麼實作 |
|---|---|
| 字級 | 標題 64px / 巨號 144px serif |
| 插槽狀態 | dashed → 巨號紅色高亮 → 灰化數字（**位置不重排**） |
| 序號 | hero-num 字體（襯線大數字） |
| 主導動作 | mask reveal（標題）+ 數字砸下（accent 紅） |
| 伴隨動作 | 副標 stagger 200ms + accent 橫線 scaleX |
| 持續微動 | active 插槽的數字 accent 光暈 `infinite` 呼吸 |
| 引子 | masthead 雙線規則 + serif 大字 |

> **新寫章節時**：抄結構（單一格線 N 個插槽、每 step 只填一個插槽、位置
> 不重排），依本章內容 + 本主題調性自由設計主導動作的形式。

## 套用熊熊視覺時

顏色和字體家族全走熊熊 token。要動的只有序號樣式和
進場動作的形式，讓它貼合新主題的調性，例如：

- 粗黑宣言型主題 → 序號換極粗字重 + 大色塊，hard-cut 砸下
- 終端機型主題 → 序號 `[01]` `[02]` `[03]` 風格，打字機進場
- 手繪 / 粉筆型主題 → 手繪底線 + wiggle 進場
- 電影感慢主題 → 數字 blur clear 慢銳化 + accent 光暈慢呼吸

**結構不變**：N+1 step、單一格線 N 個插槽、每 step 只填一個插槽。
